## Site language

- English is the default and canonical language for the entire site.
- Write all user-facing copy, navigation, accessibility labels, metadata, and error messages in natural English.
- Set the document language to `en` and keep new pages and features English-only unless the user explicitly requests localization.
- Do not introduce untranslated or mixed-language interface text.
